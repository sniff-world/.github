# Sniff.World

Sniff is a governed canine-genetics knowledge graph: cited, no-fear answers about breeds, genes, diseases, and variants, plus an honest, typed map of what nobody knows yet. Every yes has a pointer; every no has a procedure.

Live at **[sniff.world](https://sniff.world)** · field infrastructure at [sniff.world/federation](https://sniff.world/federation)

**[coverage-frame](https://github.com/sniff-world/coverage-frame)**: the CoverageFrame LinkML schema family (reasoned absence over a bounded question space), schema release landing here September 2026 alongside the LinkML Community Meeting talk.
